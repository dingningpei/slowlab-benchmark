# Phase 0：集中辐射与显热边界修正决定

日期：2026-09-27。用户已同意推荐方案。**模型口径已确定，原辐射分配选择不再阻塞；尚未实现或验证。**

## 固定的口径

保留锁定版 GreenLight 的集中辐射近似，不建立逐墙长波辐射网络。邻室/走廊只通过显式、可审计的有效显热边界修正影响气候。论文称其为带显热边界修正的集中参数模拟隔间，不称为 WUR 逐墙热工复现。

原 `v22_boundary_design.md` 中带独立墙温与热容量的方程保留为历史候选。本次不启用新增墙体储能状态，不在已有集中辐射上再次加入辐射或辐射等效热容量。

## 不重复计热的计算合同

选择以“外部参考边界替换”为修正口径。原围护路径保留为参考近似；对共享墙面 j、空气层 z 定义：

- A[j,z]：相应墙面面积，m²；
- Ueff[j,z]：有效显热边界修正系数，W/m²/K；是需明确来源/假设的有效系数，不解释为实测墙体材料导热率；
- Tb[j](t)：外生邻室/走廊温度；Tout(t)：同一时刻室外温度。

替换差额：

`deltaQ[j,z] = Ueff[j,z] * A[j,z] * (Tb[j](t) - Tout(t))`，单位 W。

这来自两条同系数参考通量之差：Ueff*A*(Tz−Tout) − Ueff*A*(Tz−Tb)。将 `sum(deltaQ)/96` 加入对应空气层原方程的热流分子。不能同时再减去完整的 Ueff*A*(Tz−Tb)，否则重新重复计算边界损失。

这只是参考模型的有效显热修正，不能宣称每个原生对流项都已精确分拆。Tb=Tout 或 Ueff=0 时修正归零；Tb>Tout 时修正向隔间供热/减少原参考损失。边界储库以相反符号记账，不伪报为本隔间供暖设备产热。

不改变短波、长波、透光或凝结公式来假装完成逐面物理模型。外生边界不依赖 LLM 动作、方法名或未来观测；同 site 同时间使用同一轨迹。跨隔间空气/水汽/CO₂ 泄漏未建模应明确声明。

## 后续验收

- 开发阶段：记录有/无修正及不同有效系数/边界轨迹的结果敏感性，不挑最有利于方法的参数。
