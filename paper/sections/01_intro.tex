Language-model agents are increasingly proposed as autonomous experimenters, and the benchmarks that evaluate them mostly let an agent query an experiment cheaply and get the answer at once \citep{boxinggym,scigym}. Experiments in physical facilities work differently. A greenhouse trial occupies a compartment for half a year, cannot be revised once it has started (a crop can only be continued or destroyed), and reveals its outcome only at harvest, while partial process measurements accumulate in the meantime. An agent in such a facility must decide what to try when every trial is a long, scarce commitment, how to schedule a few units in parallel, and whether to act on the noisy signals that arrive before the outcome. No existing benchmark tests this combination (Table~\ref{tab:related}).

We introduce \textbf{SlowLab}, a benchmark for agents running slow, irreversible experiments (Figure~\ref{fig:teaser}). An agent manages four simulated greenhouse compartments for one year: it decides when to start crops under which of a six-dimensional family of climate policies, whether to stop them, and what to read from eight sensor channels, and at the end it recommends one policy, which a private evaluator scores in three new weather years. Every site draws hidden cultivar, facility and price parameters, so the agent must learn the site from its own experiments. Two feedback conditions isolate the value of in-season measurements: under Full feedback the agent can read every process record as it arrives, under Endpoint feedback only the totals of each finished crop.

Our contributions are:
\begin{itemize}[leftmargin=*,itemsep=1pt,topsep=2pt]
\item \textbf{The benchmark.} An environment built on six design principles (slow, irreversible, facility-bound, delayed partial evidence, hidden site, private out-of-sample scoring), a hidden-instance site distribution, a blinded and fully audited agent interface, a private evaluator, and validity checks showing that the score separates strategies and that runs replay bit for bit on other hosts (Section~\ref{sec:benchmark}).
\item \textbf{A preregistered evaluation protocol with a strong reference.} Three research questions, a prior-informed local Bayesian-optimisation baseline with the same interface and budget, fixed and best-known reference points, and locked code, prompts and tests (Section~\ref{sec:setup}).
\item \textbf{Three findings} on \res{sites} unseen sites with three low-cost language models (Section~\ref{sec:results}): \textbf{(i)} the models end near a standard grower setting, \res{range.E1.abs.lo}--\res{range.E1.abs.hi}~\eur{} below the baseline; \textbf{(ii)} no method, the baseline included, profits from in-season process feedback, and the models run the facility as two synchronous batches, so in-season readings never change what they plant; \textbf{(iii)} the final reading of the evidence is not the bottleneck, which points to how the agents start and explore.
\end{itemize}
